# 기념품 반입 문의 — 사람이 승인하는 답장 발송

여행자가 "홍콩에서 비첸향 사왔는데 괜찮을까요?" 같은 문의를 보내면 AI가 관세청·검역 안내 자료로 답장 초안을 쓴다.
**위험한 초안만 담당자가 보고 발송하고, 나머지는 사람을 거치지 않고 바로 발송한다.**

되돌릴 수 없는 순간은 **답장 발송**이다. 고객은 답장대로 물건을 들고 입국한다.
검역·멸종위기종 물건에 "가져와도 된다"가 잘못 나가면 몰수·과태료·처벌로 이어진다.

설계, 기준을 고른 이유, 실행 결과는 [REPORT.md](REPORT.md)에 있다.

## 사람에게 오는 건

| 기준 | 막으려는 위험 |
|---|---|
| 근거가 검역·멸종위기종 규정이거나 물건이 그 품목인데, 판정이 **가능·조건부 가능** | 틀린 "가져와도 된다" → 몰수·과태료·처벌 |
| 재작성 후에도 **근거에 없는 숫자**가 남음 | 틀린 한도·세율을 고객이 그대로 믿는다 |
| 결론의 주장 중 **받치는 문장이 근거 문서에 없는** 것이 있음 | 숫자가 아닌 규정·절차를 지어냈다 |
| 술·담배·향수에 붙인 숫자가 근거에서 **그 품목과 짝지어 나오지 않음** | 근거에 있는 다른 숫자(기본 면세범위 800달러)를 술 한도로 붙였다 |
| 고객이 **물건 이름 없이**("기념품 사왔는데…") 물었는데 되묻지 않고 답함 | 물건이 육포인지 모르고 "신고 안 해도 된다"고 답했다 |

이 다섯에 걸리지 않으면 자동 발송한다. 면세 한도처럼 숫자로 답하고 검증을 통과한 답장, 검역 품목이라도 "불가"라고 답한 답장, 되묻기·넘김 같은 정해진 문구가 여기에 해당한다.
대기 건을 72시간 동안 아무도 처리하지 않으면 **자동 승인하지 않고** 상담사 이관 안내를 보낸다.

## 실행 방법

저장소 **루트**에서 실행한다. 이 폴더는 루트의 상담 파이프라인(`agent.py`, `context.py`, `prompts.py`, `docs/`)을 그대로 불러다 쓴다.

**1. 설치.** Python 3.10 이상.

```bash
pip install -r requirements.txt
```

**2. API 키.** 루트에 `.env`를 만들고 `OPENAI_API_KEY=sk-...`를 한 줄 적는다(`.env.example` 참고). `.env`는 `.gitignore`에 들어 있어 올라가지 않는다.

**3. 자체 점검.** API 없이 돈다. 멈춤·보관·재개·중복 발송 방지·72시간 규칙을 가짜 모델로 확인한다.

```bash
python hitl/hitl.py
```

**4. 문의 51건 접수와 기준 비교.** OpenAI를 약 250번 부르고 10분쯤 걸린다. 끝나면 기준에 걸린 건이 데모의 승인 대기에 쌓여 있다.

```bash
python hitl/sweep.py
```

표만 다시 만들 때는 API를 부르지 않는다.

```bash
python hitl/sweep.py --table
```

에이전트는 다시 돌리지 않고 저장된 초안을 다른 채점기로 다시 채점만 할 수도 있다(REPORT의 표는 gpt-4.1 채점).

```bash
python hitl/sweep.py --regrade gpt-4.1
```

읽기 단계(판정·주장별 인용·물건 미특정)를 고친 뒤에는 초안은 그대로 두고 읽기만 다시 한다.

```bash
python hitl/sweep.py --reread
```

**5. 웹 데모.**

```bash
streamlit run hitl/app.py
```

## 데모에서 해 볼 것

1. **문의 받기**에서 `비첸향 육포`를 누르고 접수한다. 발송되지 않고 승인 대기로 간다.
2. `술 몇 병`을 접수한다. 기준에 걸리지 않아 바로 발송된다.
3. **승인 대기**에서 한 건을 연다. 요청 원문, 멈춘 이유, AI 초안과 판정, 주장마다 받치는 규정 원문, 통과시켰을 때 일어나는 일을 보고 넷 중 하나를 고른다.
   - 그대로 승인: 초안을 발송한다
   - 고쳐서 승인: 고친 글을 발송한다
   - 반려: 발송하지 않는다. 사유를 반드시 적는다
   - 다시 판정: 지시를 적으면 AI가 초안을 다시 쓰고, 다시 이 화면으로 돌아온다(최대 2회)
4. 터미널에서 데모를 껐다가 다시 켠다. 처리하지 않은 대기 건이 그대로 남아 있다.
5. **처리 내역**에서 건별 상태와 발송함(고객에게 실제로 나간 답장)을 본다.

## 파일

| 파일 | 하는 일 |
|---|---|
| `hitl.py` | 승인 그래프. 초안 읽기(read) → 기준 판단(risk) → 멈춤(review) → 발송(send)·반려(reject)·다시 판정(redo) |
| `app.py` | Streamlit 승인 데모 |
| `sweep.py` | 51건 접수, 채점, 기준별 비교표(`criteria.md`) 생성 |
| `cases.json` | 문의 51건과 "사람이 봐야 하나" 라벨, 라벨 이유 |
| `criteria.md` | 기준별 개입률·놓침·헛멈춤 표와 건별 신호 |
| `runs/` | 대기 건 저장소(`checkpoints.sqlite`), 발송함(`outbox.jsonl`), 초안(`drafts.json`). 올리지 않는다 |
